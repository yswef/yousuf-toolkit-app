# عقد المزامنة مع لوحة الأم — Y- Dimensions

| البند | القيمة |
|---|---|
| صاحبة الكود والرمز | لوحة الأم فقط |
| كود مستقل في هذه اللوحة | لا |
| رمز/مفتاح/نقطة دخول محلية | لا |
| قاعدة البيانات | واحدة موحّدة، `mother_panel.db.shared` |
| العزل | `app_id = y-dimensions` في كل استعلام، بلا خلط بيانات بين التطبيقات |

## الرئيسية والإحصائيات
`mother_panel.stats.home` يعرض عدد المستخدمين وكل إحصائيات التطبيق: التنزيلات، التراخيص (الكلي/المفعّل/الملغى)، التقييمات ومتوسطها، الزيارات، المستخدمين الجدد، آراء العملاء، مقالات المدونة، وعمليات المزامنة. المصدر `stats.json`، بلا بيانات عيّنة.

## لوحات الإدارة
`mother_panel.boards.cards` يولّد بطاقة صغيرة لكل لوحة من `boards` + `board_stats`، بإحصائيات منفصلة لكل تطبيق (`data-isolation="app_id"`)، بلا جمع أو مقارنة بين التطبيقات.

## الحسابات
`mother_panel.accounts.register` ينشئ حساباً في الجدول الموحّد `users` بمفتاح `(app_id, email)` فقط، بلا إنشاء تلقائي في التطبيقات الأخرى، مع السماح بنفس البريد.

## التراخيص (التطبيقات المدفوعة)
ثلاثة أفعال من مكان واحد: `mother_panel.licenses.create` و`mother_panel.licenses.revoke` و`mother_panel.licenses.activate`، كلها تكتب في `board_licenses` وتُسجَّل في `audit_log` و`sync_log`. لا توليد كود ولا `license_secret` داخل اللوحة.

## المدونة والتطبيقات الأخرى
`mother_panel.blog.list` للمدونة الموحّدة، و`mother_panel.apps.sisters` لبطاقات التطبيقات الشقيقة عند المطوّر، ويُسلَّم القسم لتطبيق الموبايل عبر `mother_panel.app_config.sister_apps` بلا تعديل ملفات التطبيق.

## التثبيت والتحقق
`mother_panel.install.map` ينفّذ `MAP.json` بالترتيب، و`mother_panel.verify.run` يتحقق من الوجود والترتيب والبصمات والتوقيعات وغياب DDL وحلّ المراجع قبل إعلان الاكتمال.
