# Y- Dimensions — لوحة تحكم تابعة للوحة الأم

- التطبيق: **Y- Dimensions** — نوعه **موبايل** فقط.
- المطوّر: **يوسف الحمزي** — البريد `yswefalhmzy@gmail.com` كما ورد حرفياً من المطوّر.
- ملف بيانات التطبيق `app.json` يعبّئه الموديل ويراجعه المطوّر فقط: الاسم، الوصف، التاجات، علامات البحث، الإصدار، الأيقونة، التوثيق.
- الأيقونة `assets/icon.svg` تُستخدم في بطاقة عرض اللوحة في لوحة الأم.

## القاعدة الأساسية
لوحة الأم وحدها تحوي الكود والرمز. هذه اللوحة **بلا كود مستقل**: لا PHP، لا JavaScript، لا نقطة دخول، لا اتصال قاعدة بيانات، لا رمز ولا مفتاح. كل الملفات تعريفات JSON، وقوالب HTML بعناصر `data-hook` وعناصر نائبة `{{...}}`، وملف أنماط، وأيقونة، وتوثيق. لوحة الأم هي التي تُصيّر القوالب وتنفّذ كل قراءة وكتابة عبر `mother_panel.db.shared`.

## الأقسام
| القسم | الملف | الوظيفة |
|---|---|---|
| الرئيسية | `sections/home.json` | عدد المستخدمين وكل إحصائيات التطبيق (تنزيلات، تراخيص، تقييمات، زيارات…) |
| لوحات الإدارة | `sections/admin-boards.json` | بطاقة صغيرة لكل لوحة بإحصائياتها منفصلة، كل تطبيق منفصل عن الآخر |
| الحسابات | `sections/accounts.json` | حساب مستقل لكل تطبيق، نفس البريد مسموح، بلا انتشار تلقائي |
| التراخيص | `sections/licenses.json` | إنشاء/إلغاء/تفعيل من مكان واحد عبر لوحة الأم للتطبيقات المدفوعة |
| المدونة الموحّدة | `sections/reviews.json` | مدونة واحدة = آراء وتقييمات العملاء عن التطبيقات |
| التطبيقات الأخرى | `sections/sister-apps.json` | بطاقات وروابط للتطبيقات الشقيقة، تُسلَّم لتطبيق الموبايل عبر إعدادات لوحة الأم بلا تعديل ملفات التطبيق |
| بيانات التطبيق | `sections/settings.json` | تسجيل بيانات المطوّر والتطبيق |

## التثبيت
1. تقرأ لوحة الأم `MAP.json` وتُنفّذ خطوات `install.order` بالترتيب الرقمي 1…N، وتحفظ المسارات في `app_files` و`board_files`.
2. التحقق الإلزامي في `MAP.json#/verify` **قبل** إعلان الاكتمال: الوجود، الترتيب، البصمات، صحة JSON، توقيع المطوّر، absence of DDL، غياب جدول مستخدمين محلي، حلّ كل مراجع `mother_panel.*`.
3. عند أي فشل: `abort_and_rollback`. عند النجاح: `mark_installed_and_report`.
4. التقرير المُنفّذ فعلياً في `docs/VERIFY.md`.

## قاعدة البيانات
`docs/DATABASE.md` يسرد كل الجداول الموجودة (24 جدولاً) مع أنواع المتغيّرات التي يحتاجها ويستخدمها هذا التطبيق فقط، والجدول الموحّد `users` الذي لا يُنشأ ولا يُكرّر. لا توجد أي عبارة إنشاء أو تعديل جدول في هذه اللوحة.

## عقد المزامنة
`docs/SYNC.md` و`sync.json`: سجل الـ hooks، عزل `app_id`، وحدة التراخيص، وحدة المدونة، فصل الحسابات.

## حدود العمل
خريطة التثبيت لا تلمس أي ملف خارج المجلد `server/public/boards/y-dimensions/`؛ التحقق يقيس نطاق التثبيت فقط. التعديلات اللاحقة على شاشات التطبيق جاءت بطلب مستقل من المطوّر لتنفيذ معاينات `docs/design/mockups`، ولا تدخل في تثبيت اللوحة. لوحة `server/public/admin` الحالية تعود لتطبيق آخر في المستودع وتركت كما هي، التزاماً بعدم التعميم على تطبيقات أخرى.
