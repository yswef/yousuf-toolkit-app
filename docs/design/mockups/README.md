# معاينات Y-Dimension

صفحات HTML ثابتة (412×915، RTL) لمراجعة الشكل قبل تحويله إلى Compose.

## التشغيل

```bash
cd docs/design/mockups
python3 -m http.server 8080
```

افتح <http://localhost:8080>. الصور الفارغة تُحمّل من `app/src/main/res/drawable-nodpi/` مباشرة.

## الملفات

| الملف | الغرض |
|---|---|
| `index.html` | فهرس الشاشات والألوان وقواعد القرار |
| `tokens.css` | كل الألوان والمسافات والحركة. المرجع الوحيد |
| `app.js` | الأيقونات، الوضع، الحركة، الخط، العدادات، الورقة السفلية |
| `today.html` | التبويب الأول: تحية + XP + مهام + عادات |
| `tasks.html` | المهام والفلاتر والتجميع |
| `money.html` | الرصيد والرسم والسجل |
| `tools.html` | مكتبة كتب سحرية + فتح فصول |
| `achievements.html` | الرتب والأوسمة والحملات |
| `stats.html` | حلقات وسلسلة وتوزيع |
| `account.html` | الملف والإعدادات والبيانات |
| `quick-add.html` | الورقة السفلية |
| `tool-water.html` | أداة نموذجية |
| `store.html` | المتجر |
| `forum.html` | المنتدى |
| `states.html` | فارغ/تحميل/خطأ/بدون إنترنت |
| `assets/nour.webp` | صورة المعلمة نور الجديدة |
| `audio/nour-intro.mp3` | صوت نور في المقدمة |
| `audio/nour-rank.mp3` | تهنئة نور عند الرتبة |
| `REVIEW.md` | ما فُحص وأُصلح والقيود |

## ملاحظات

- المبدلات في الأعلى (فاتح/داكن، الحركة، 130%) تُحفظ في المتصفح.
- الصفحات لا تتصل بأي خادم، ولا تحتوي أي بيانات حقيقية.
- لا تُنقل الصفحات إلى التطبيق؛ تُنقل القيم فقط بعد الاعتماد.
