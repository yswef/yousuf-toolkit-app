توثيق Y-Dimension

تطبيق أندرويد (14+) يحوّل تنظيم حياتك اليومية إلى لعبة بطابع الأنمي: مهام، مال، صحة، تعلّم، عبادة، وأدوات جهاز. يعمل بالكامل دون إنترنت، والخادم اختياري للمزامنة والمنتدى والمتجر.

المقدمة

كل شيء يُحفظ محلياً في ملف JSON على جهازك. كل عمل تنجزه يمنحك نقاطاً وخبرة (XP) ترفع رتبتك. الواجهة Material 3 بخط Cairo، مع حركات انتقال وأصوات يمكن إيقافها من الإعدادات.

البدء

  1. ثبّت ملف APK وافتح التطبيق (تظهر المقدمة وشخصية «نور»).
  2. أكمل الملف الشخصي (الاسم، الهدف).
  3. من الإعدادات ← «الصلاحيات والمهام» فعّل ما تحتاجه.
  4. أضف مهمتك الأولى من الزر العائم، أو اكتب سطراً ذكياً مثل: اجتماع غداً 5م.

المميزات

  • المهام: أولويات، تكرار، تذكير، إدخال ذكي.
  • المال: دخل/مصروف، تصنيفات، محافظ، ميزانية.
  • الصحة: ماء، نوم، تمارين مع خطط جاهزة، عناية بالبشرة وبالأكل.
  • التعلّم: مسارات تعليمية فعلية بدروس تُنجز وتمنح نقاطاً.
  • المكتبة: كتب وتقدم القراءة. اليوميات والإيمان.
  • الجهاز: وقت الشاشة، حظر التطبيقات المشتتة، تلخيص الإشعارات، الخزنة.
  • الخادم: حساب، مزامنة، منتدى، متجر، حملات (غارات)، ترخيص.

الصلاحيات والمهام

من الإعدادات ← الصلاحيات والمهام: لكل صلاحية حالتها وزر «تفعيل» يفتح الطلب أو الشاشة المناسبة من النظام. كل صلاحية مفعّلة تمنح 10 نقاط مرة واحدة، وإكمال الكل يمنح 50 نقطة إضافية. كلها اختيارية، والميزة المرتبطة فقط هي التي تتوقف دونها.

النقاط والرتب

النقاط تُصرف في المتجر (الخادم) وللدرع والتجميد. السحب للحذف يخصم ما مُنح، حتى لا تُكسب نقاط بالتكرار. الرتبة تُحسب من XP.

منظّف التخزين

يفحص الملفات المكررة (SHA-256)، والكبيرة، والمجلدات الفارغة، وبقايا التنزيلات. لا يحذف شيئاً قبل مراجعتك وتأكيدك، ولا يلمس مجلد Android/ ولا المجلدات القياسية العليا، ويحذف المجلدات الفارغة فقط.

الأنمي والمسلسلات

بحث بالاسم (Jikan/MyAnimeList للأنمي، TVMaze للمسلسلات، بلا مفاتيح)، حفظ بالملصق والعنوانين والقصة والشخصيات. للعناصر غير المكتملة فحص كل ~6 ساعات وعند فتح التطبيق، وإشعار بحلقة جديدة. القائمة في watchlist.json ولا تدخل في النسخ الاحتياطي حالياً.

الخادم الاختياري

  1. أنشئ قاعدة MySQL على Hostinger وشغّل server/migrations/001_init.sql ثم 002_admin.sql.
  2. انسخ config.example.php إلى config.php (لا يُرفع إلى Git) واملأ قاعدة البيانات، license_secret وadmin_token (12+ حرفاً عشوائياً).
  3. ارفع محتوى server/public إلى public_html والمجلدات src وconfig خارج الجذر العام أو ضمن حماية .htaccess.
  4. في التطبيق: الإعدادات ← الحساب ← أدخل عنوان الخادم.

لوحة التحكم

الرابط: /admin/ — مجلد واحد مستقل (server/public/admin) يمكن رفعه أو دمجه مع لوحة أخرى. الدخول بالرمز admin_token. بعد 5 محاولات خاطئة يُقفل الدخول مؤقتاً، والجلسة 8 ساعات، وكل نموذج محمي بـCSRF، وكل إجراء يُسجَّل.

البناء والنشر

GitHub Actions يبني APK عند دفع وسم (مثل v0.13.0). محلياً: ./gradlew assembleRelease (انظر docs/dev/BUILD_LOCAL.md). الحد الأدنى Android 14.

الخصوصية

لا تحليلات ولا إعلانات. البيانات محلية؛ لا يُرسل شيء للخادم إلا إن سجّلت حساباً وفعّلت المزامنة. بحث الأنمي يرسل نص البحث فقط إلى Jikan/TVMaze.
