# صفحة الخطة والمراجعة

- `plan.html`: رابط إنجليزي قصير لصفحة الخطة كاملة، ويعمل دون إنترنت.
- `خطة كل ما يحتاجه يوسف.html`: النسخة نفسها بالاسم العربي.

تحتوي الصفحة: الفكرة والمميزات والتطبيقات المرجعية، ثم **قائمة تحقق** لكل تطبيق ومميزاته، و**المدفوعة**، و**الاقتراحات**، و**ملاحظاتي** بترتيب تلقائي وزر نسخ.

كل التحديد والملاحظات تُحفظ في متصفح الجهاز نفسه عبر `localStorage`.
