# بيانات الملف الشخصي وصوت نور

## ما تغيّر
- نموذج الملف الشخصي صار يشمل تاريخ الميلاد والطول والوزن والجنس ومستوى النشاط، والعمر يُحسب تلقائيًا من تاريخ الميلاد، ومؤشر كتلة الجسم يُحسب من الطول والوزن.
- شاشة التسجيل وشاشة حسابي تجمعان الحقول الجديدة، وبطاقة التفاصيل في حسابي تعرضها كلها.
- صوت نور لم يعد ينادي باسم «يوسف»؛ التهنئة والترحيب عامّان لأي مستخدم.
- تهنئة الرتبة تظهر مرة واحدة عند الصعود لرتبة جديدة، مع زر لتشغيل صوت نور.
- رجوع صورة نور إلى الصورة المعتمدة السابقة في التطبيق وصفحات المراجعة.
