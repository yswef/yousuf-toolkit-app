# الإصدار 0.11.0-test.1 — الواجهة الجديدة

- التاريخ: 2026-11-20
- الفرع: arena/4d1420c5-yousuf-toolkit-app

## التغييرات

- التبويبات السفلية: اليوم | المهام | المال | الأدوات.
- «اليوم» جديد: تحية، بطاقة رتبة وXP، مهام اليوم، الماء والصلاة والنوم، وإحصاءات سريعة.
- المهام والمال يعملان داخل تبويبيهما مع الحفاظ على كل الأدوات: المزيد، الميزانية، المحافظ، استيراد الرسائل، الديون.
- الحساب والمسار والإحصائيات صارت شاشات مستقلة تُفتح من صورة الحساب، بطاقة XP، والإحصاءات السريعة.
- الألوان: بنفسجي الهوية `#6C4CF1` / `#B8A6FF`، أسطح فاتحة وداكنة جديدة، وذهب للمكافآت فقط.
- مكتبة الأدوات: بحث فوري فوق الكتب السحرية.
- نور: صورة جديدة، وصوت في المقدمة، وبطاقة تهنئة بالرتبة مع زر تشغيل.
- الإعدادات والوضع الليلي لم تُحذف أي ميزة منها.

## التحقق

- بناء `assembleQa` نجح قبل الإصدار.
- ينشر كـ APK اختبار `v0.11.0-test.1`.
