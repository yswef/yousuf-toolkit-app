# docs/dev

- `RULES.md`: قواعد الفريق. اقرأها قبل أي عمل.
- `CHANGELOG.md`: مؤشر ملفات التعديل.
- `changes/`: ملف تعديل لكل عمل، باسم `YYYY-MM-DD_model_feature.md`.
- `SYMBOLS.md`: فهرس الدوال والكلاسات والمتغيرات المهمة.
- `modules/`: ملف توثيق لكل وحدة أو شاشة، من القالب `modules/_template.md`.

- `BUILD_LOCAL.md`: بناء التطبيق محلياً على Windows/macOS/Linux، وتثبيته عبر adb، وحدود Termux.
