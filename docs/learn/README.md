# قالب المواقع التعليمية

كل خطة تعليمية تُجمع في ملف ZIP واحد:

- `course.md`: الخطة المنظّمة، الأهداف، الدروس، التحفيز، المهام، العادات، والاختبارات.
- `roadmap.xml`: خريطة المسارات والدروس.
- `site.html`: نسخة مستقلة من `course-template.html` بقائمة جانبية وتبويبات ودروس تُشطب عند الإتمام.
- `plan.json`: البيانات المقروءة آلياً بالمخطط `y-dimensions.learning-plan/1.0`.

البرومت يمنع أسماء الأشخاص وادعاءات الحقوق. التطبيق يرفع الخطة المستوردة إلى `learning.php?action=upload`، واللوحة تعرض نوع الكورس وتراجع `course.md`، وبعد الاعتماد يُنشر `site.html` في `/learn/{id}/` ويُحدَّث `plans.json`، ثم تسحبها بقية التطبيقات عبر `action=ready` و`action=plan`. `site.css` هو المصدر الموحّد للتصميم، و`course-template.html` يضمّنه داخل الصفحة حتى تعمل النسخة بلا ملفات إضافية.
